# Rotating the shared VPN pre-shared key (retired)

> **Retired 2026-06-01.** Meridian private networks no longer use a shared pre-shared
> key. Mutual TLS with per-device certificates replaced it in client release 2026.06.
> Follow `vpn-001` instead. This page is retained only for audit history.

## Former procedure (no longer valid)

1. Request the current pre-shared key from the Network Access team.
2. Enter the key in the client under **Settings > Advanced > PSK**.
3. Reconnect.

The **Settings > Advanced > PSK** field no longer exists in supported clients. Any
runbook or ticket macro still instructing a user to request the shared key should be
updated to point at `vpn-001`.
